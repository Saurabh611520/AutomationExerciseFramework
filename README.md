# Automation Exercise - Selenium Framework

This is a complete end-to-end automation framework built for https://automationexercise.com

### 🚀 Tech Stack
- Java + Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Git & GitHub

### 📁 Project Structure
src/main/java - Page Objects
src/test/java - Test Cases
pom.xml - Dependencies
testng.xml - Test Suite

### ▶️ How to Run
mvn test
